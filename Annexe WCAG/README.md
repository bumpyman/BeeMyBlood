# Annexe WCAG

Ce dossier sert de dépôt pour les tests d'accessibilité réalisés avec des
outils externes (audits automatiques, rapports d'analyse de contraste,
résultats de lecteurs d'écran, etc.).

Il ne fait pas partie du site (`beemyblood_project/sites/`) et n'est donc
jamais chargé ni servi par BeeMyBlood — c'est uniquement une annexe pour
le travail de bachelor.
